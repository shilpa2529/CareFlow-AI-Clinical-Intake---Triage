📐 Prompt Iteration Engineering Notes

v1 → v2 Evolution

Added role framing and strict JSON type definitions. Fixed conversational preamble that broke automated pipelines. Handled unstated details using explicit null rules instead of hallucinations.

v2 → v3 Evolution

Introduced clinical few-shot examples and calibrated triage rubric for ROUTINE, SOON, and URGENT. Added hard anti-diagnosis guardrails and treated input as passive untrusted data to mitigate prompt injection.

Safety Invariant

Regardless of prompt version, the algorithmic keyword safety net (evaluateRedFlags) acts as an independent failsafe to guarantee critical red flags are never under-triaged.
